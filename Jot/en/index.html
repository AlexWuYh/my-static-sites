What it is

A local-first fragment notes app

Capturing and summarizing are two separate things: capturing stays light and on-device; summaries are a dedicated module you generate only when you want.

FocusDaily fragment notes plus optional AI period summaries
DataOn-device SQLite by default; export and encrypted backup
AILocal models (e.g. Ollama) or cloud models (OpenAI-compatible vendor presets)
SyncOptional end-to-end encrypted snapshot sync on storage you own
Features

Capture lightly, review clearly

Low-friction capture

The composer sits at the top of the page, with Markdown preview and backdating. On desktop there is a tray icon and a global hotkey (default Alt+Shift+J).

AI daily / weekly / monthly / yearly summaries

Summaries build up period by period, with a condensed item list at the top that merges scattered fragments and groups them by period.

Four summary styles

Pick one in Settings: balanced, concise, reflective or narrative.

Restorable version history

When you regenerate or edit a summary, earlier versions are kept and can be restored anytime.

Local or cloud models

Local and cloud use separate endpoints, and cloud API keys are stored separately per vendor.

Scheduled summaries

Get a reminder that it is time to summarize, or generate automatically. Auto-generation is opt-in.

Search and activity

Full-text search, plus an overview of the last 7 and 30 days and your current streak.

Multi-platform, bilingual

Installers for Windows, macOS and Android; the UI supports Chinese and English, with a soft purple accent.

Free and open source

MIT-licensed. Source code, installers and developer docs are all on GitHub.

How it works

Three steps

Jot a line

Write whatever comes to mind: what you read, discussed or did. One sentence is enough.

Fragments become a timeline

Each fragment is filed by time on your device. Search it, backdate it — no network needed.

Let AI summarize when needed

Choose a period and a style, then generate a daily, weekly, monthly or yearly summary. If you configure no model, it never happens.

Privacy

Your fragments stay with you by default

How data is handled

  • Notes and summaries are stored on your device by default
  • Text is sent to a cloud model only when you generate a summary for a selected range with a cloud provider
  • API keys live in the system secure store and are excluded from plain exports

Syncing across devices

  • Sync is optional and runs on storage you provide (folder, WebDAV or S3)
  • Synced data is end-to-end encrypted; storage providers only see ciphertext
  • Prefer to stay offline? A local model (e.g. Ollama) keeps everything on your machine

Android

Sideload the APK. Not on Play Store.

jot-*-android-release.apk
Go to download

Note: The Android package is built by CI and signed with a debug keystore, so you need to allow installing apps from this source. There is no iOS installer yet; you can build it yourself with Flutter following the repository instructions.
