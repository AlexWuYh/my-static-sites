What it is

一款本地优先的碎片笔记

记录和总结是两件事：记录永远轻、永远在本机；总结是一个独立模块，想要时才生成。

定位日常碎片笔记，加上可选的 AI 周期总结
数据默认存在本机 SQLite；支持导出与加密备份
AI本地模型（如 Ollama）或云端模型（OpenAI 兼容的厂商预设）
同步可选：用你自己的存储做端到端加密的快照同步
Features

记得轻，回顾得清楚

低摩擦记录

输入框就在页面顶部，支持 Markdown 预览，也能补记过去的日期。桌面端有托盘和全局热键（默认 Alt+Shift+J）。

AI 日 / 周 / 月 / 年总结

按周期逐层汇总，文首有“事项归纳”，把零散碎片合并概括、按周期分组。

四种总结风格

在设置里选择：均衡复盘、简洁清单、深度复盘或日记叙事。

历史版本可恢复

重新生成或手动编辑总结时，旧版本都会保留，随时可以恢复。

本地与云端模型都行

本地和云端使用各自独立的地址，云端的 API Key 按厂商隔离保存。

定时总结

可以只提醒你该总结了，也可以自动生成。自动生成需要你明确开启。

搜索与活跃概览

支持全文搜索，并能看到近 7 天、30 天的记录情况和连续记录天数。

多平台，中英双语

提供 Windows、macOS、Android 安装包，界面支持中文和 English，主色是柔和的紫。

免费开源

以 MIT 协议开源，源码、安装包和开发文档都在 GitHub 上。

How it works

三步用起来

随手记一句

想到什么就写什么：读了什么、聊了什么、做了什么。一句话就够。

碎片自动成时间轴

每条碎片按时间归档在本机，可以搜索、补记，不依赖任何网络。

需要时让 AI 总结

选好周期和风格再生成日、周、月或年总结。不配置模型，就完全不会发生。

Privacy

你的碎片，默认只在你手里

默认怎么处理

  • 笔记和总结默认保存在本机
  • 只有你用云端模型生成某个时间范围的总结时，那段文字才会发给云端模型
  • API Key 存放在系统安全存储里，普通导出不会包含它

想要多设备同步

  • 同步是可选的，由你自己提供存储（文件夹、WebDAV 或 S3）
  • 同步内容端到端加密，存储服务商只能看到密文
  • 不想联网，用本地模型（如 Ollama）就能全程离线
