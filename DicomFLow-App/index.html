Features

拿到片子，不用再到处找阅片软件

医院拷给你的光盘或压缩包里是 DICOM 文件，普通电脑和手机打不开。DicomFlow 帮你一步转成能直接播放、能发给医生的视频。

转成 MP4 或 GIF

MP4 最适合发给医生播放，GIF 适合在聊天里快速查看。多个序列还可以合并成一个文件。

数据可控

App 全程在本机转换，网页版结果定时自动清理。没有账号体系，也不需要云端存储。

直接用压缩包

医院给的压缩包直接选就行，不用先手动解压。App 已内置 ffmpeg 与 7-Zip，Windows 安装包开箱即用。

预览再导出

转换后先预览。App 支持逐片查看、捏合或滚轮放大，网页版支持在线预览与下载。

方便转发给医生

微信、相册、电脑播放器都能打开转换后的文件，会诊沟通、家属转存都更省事。

免费开源

网页版与 App 都以 MIT 协议开源，源码、发行包和 Docker 镜像都能在 GitHub 上获取。

How it works

三步完成

选择压缩包

选择医院给的 zip / rar（App 还支持 7z），也可以直接拖进窗口。

选格式并转换

选 MP4（发给医生更合适）或 GIF，需要时把多个序列合并成一个文件，然后开始转换。

预览并保存

预览满意后下载或分享。网页版的结果默认只保留 24 小时，请及时保存。

Formats

支持转换的片源

你拿到的医院 CT / MRI 片子：DICOM 影像（医院拷盘、光盘里常见的那种）
压缩包网页版：zip、rar；App：zip、rar、7z
包里的文件.dcm、.dicom、.ima，或没有后缀的 DICOM 文件
转成MP4 视频或 GIF 动图

提示：常见的未压缩、JPEG、RLE 编码的片子都可以转换。JPEG 2000 等特殊压缩可能转不了， 可以请医院改为导出未压缩或 JPEG 格式。

它会做的

  • 把 DICOM 转成 MP4 / GIF，方便播放与转发
  • 预览转换结果
  • 下载、分享或导出结果

它不会做的

  • 诊断：没有测量、调窗、MPR
  • 替代医院的专业阅片设备
  • 账号体系或云端存储

DicomFlow 仅便于沟通查阅，不作诊断依据，也不是医疗器械。如需诊断，请使用医院提供的专业阅片软件，并遵循医生的建议。
